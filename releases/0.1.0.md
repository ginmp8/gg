# Gita 0.1.0 — original source baseline

**Status:** Historical source snapshot; **not** a published GitHub Release.
**Application name at this version:** **Gita** (before the later GG Analytics branding).
**Source:** [main at `465d8b984c1e17e6a5763b60b527cfad5831973f`](https://github.com/ginmp8/gita/tree/465d8b984c1e17e6a5763b60b527cfad5831973f)
**Source commit date:** July 29, 2026 (not a verified release date).
**Version evidence:** The root and workspace `package.json` files at that commit declare `0.1.0`. No `v0.1.0` tag or GitHub Release was found when these notes were prepared.

These notes describe the code present in the original `main` snapshot. They do **not** describe the later GG Analytics development branch, and they deliberately do not link to the continuously updated project README as release documentation.

## What Gita 0.1.0 included

### Projects and repository management

- Create, list, edit and delete local projects, and register multiple repositories per project.
- Register local Git repositories or remotes supplied as HTTPS, SSH, or GitHub `owner/repository` shorthand.
- Refresh a whole project or an individual repository on demand, with queued/running/succeeded/failed status and progress information.
- Aggregate results across repositories in a project, or narrow the dashboard to one repository.

### Analytics and exploration

- Project and repository summaries for commits, insertions, deletions, net line change and churn.
- Contributor activity, leaderboards, identity normalization and file-type contribution breakdowns.
- Activity timelines, file-type analytics, hot files and repository comparisons.
- Branch information and reusable named branch views with per-repository include/exclude folder filters.
- Filters for repository, contributor, date range, branch, folder and metric.
- Optional GitHub pull-request and related provider metadata obtained through the local `gh` CLI. Core Git analytics remain usable when `gh` is unavailable.

### Local-first behavior and architecture

- Next.js App Router dashboard backed by a separate Fastify API/refresh worker.
- TypeScript, npm workspaces, Turborepo, React, Tailwind CSS, Radix UI, Apache ECharts and TanStack Table.
- SQLite with Drizzle ORM for local analytics and repository metadata.
- Git analysis through local commands; app-owned bare mirrors cached under `.gita/repos/`, with `git fetch --prune` for subsequent updates. The analyzed source repositories are not modified by Gita.
- MIT-licensed original source.

## Running this historical snapshot

Requires Node.js 24+, npm and Git; `gh` is optional for GitHub metadata.

```bash
git clone https://github.com/ginmp8/gita.git
cd gita
git checkout --detach 465d8b984c1e17e6a5763b60b527cfad5831973f
npm ci
npm run dev
```

The historical web UI listens on `http://127.0.0.1:4444` and the local API on `http://127.0.0.1:4443`. Local data is held in `.gita/`. This command sequence reproduces the **source version**, not a signed installer or formally published release.

## Metrics and limitations

- Git `--numstat` reports changes over time, **not** current code ownership or developer performance.
- Merge commits appear in commit counts but do not contribute to contributor line-change totals; binary files do not provide normal line totals.
- Branch creation times are not reliably available from Git; GitHub PR information requires the optional provider integration.
